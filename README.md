# Maxim's Games Collection

This repository unifies multiple game projects into a single codebase, with each project neatly structured into its own folder.

## [Game of Life](https://maxim-isacescu.itch.io/game-of-life)
**Folder:** `game-of-life/`
A digital cellular automaton or simulation game inspired by the classic Conway's logic. Check out the game page on itch.io for more details and to play.

## [Room 404](https://maxim-isacescu.itch.io/room404)
**Folder:** `storytelling/`
A narrative and visual storytelling game centered around a creepy environment, strange hallways, and mystery. Play the game via the itch.io link.

## [The Island](https://maxim-isacescu.itch.io/the-island)
**Folder:** `the-island/`
An adventure set on an island. Experience the game and explore its mechanics on the official itch.io page.
