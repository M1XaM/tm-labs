# Games Collection

This repository unifies multiple game projects into a single codebase, with each project neatly structured into its own folder.

## Game of Life
**Folder:** `game-of-life/` or branch `game-of-life`

Developed in Unity, this project is a neural network activity simulation inspired by Conway's classic Game of Life automaton. Rather than just replicating the original, it models the behavior of neurons by dividing the grid into functional "brain" regions. These regions alter the basic rules of cellular birth and death to mimic neurological activity variations, allowing you to explore custom themes and unique environmental modifications. You can play and explore the simulation on [its official itch.io page](https://maxim-isacescu.itch.io/game-of-life).

## Room 404 (Storytelling)
**Folder:** `storytelling/` or branch `storytelling`

Built using the Godot Engine, Room 404 is an atmospheric visual narrative game centered around mystery and survival. You awaken in the titular Room 404—your head pounding, accompanied only by the dim glow of a bedside lamp and the scent of decay. As you traverse through creeping unease, dusty environments, and strange hallways of a seemingly forgotten place, every choice counts. You can experience the story firsthand on [its itch.io page](https://maxim-isacescu.itch.io/room404).

## The Island
**Folder:** `the-island/` or branch `the-island`

A 2D farming and adventure game built with Godot and C#. The Island puts you in a tile-based world where you must cultivate crops, manage your inventory with a dedicated system, and interact with your environment. It features character movement, item management, and active time-based farming mechanics. You can begin your farming adventure over on [The Island's itch.io page](https://maxim-isacescu.itch.io/the-island).
